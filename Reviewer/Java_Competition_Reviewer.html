10 Golden Rules (memorize these)

1. nextInt() then nextLine() skips input. After any nextInt()/nextDouble(), the Enter key stays in the buffer. Call sc.nextLine(); once (throwaway) before reading text, or always read numbers via Integer.parseInt(sc.nextLine()).
2. int overflows silently past ~2.1 billion. Sums/products that can exceed 2×109 must use long (safe to ~9.2×1018). Cast first: long big = (long)a * b;
3. Never compare Strings with ==. Use a.equals(b) or a.equalsIgnoreCase(b). == compares memory addresses, not text.
4. Integer division truncates. 5/2 == 2, not 2.5. For a decimal average: (double) sum / n. Also 5 % 2 is the remainder (1).
5. Binary search needs sorted data. Linear search works anywhere; binary search is only for sorted arrays.
6. Array index out of bounds = runtime crash. Valid indexes are 0 .. length-1. Careful with a[i+1] and a[i-1].
7. Recursion needs a base case that is actually reached. If the parameter never changes toward it, you get StackOverflowError.
8. % by zero crashes. Check the divisor before dividing or taking remainders.
9. doubles compare with epsilon: Math.abs(a-b) < 1e-9, never with ==.
10. Print a LOT of lines? Build one StringBuilder and System.out.print(sb) once at the end — much faster.

Bitwise tricks that win contests

if ((n & 1) == 0)        // even check (faster than n % 2 == 0)
n >> 1                   // same as n / 2     (halve)
n << 1                   // same as n * 2     (double)
n >> k                   // n / 2^k
a ^ b ^ b == a           // XOR trick: find the unique element when pairs cancel

Swap without a temp variable

a = a + b;  b = a - b;  a = a - b;      // arithmetic swap
// XOR swap: a ^= b;  b ^= a;  a ^= b;
XOR/arith swap fails if a and b are the same array slot (a[i], a[j] with i==j) — you zero it out. Guard with if (i != j).

4. Conditionals & switch

if / else-if / else

if (score >= 90) {
    System.out.println("A");
} else if (score >= 80) {
    System.out.println("B");
} else {
    System.out.println("Needs Improvement");
}
Order matters! Check the highest range first. score >= 80 is also true for a 95, so an incorrect order mislabels grades.

Switch — classic and arrow forms

switch (day) {                        // works on int, char, String, enum
    case 1:  System.out.println("Mon"); break;   // break! or it falls through
    case 2:  System.out.println("Tue"); break;
    default: System.out.println("Invalid");
}

switch (day) {                        // arrow form: no break needed (Java 14+)
    case 1 -> System.out.println("Mon");
    case 2 -> System.out.println("Tue");
    default -> System.out.println("Invalid");
}

switch (grade) {                      // multiple labels share one branch
    case 'A': case 'B':
        System.out.println("Pass"); break;
    default:
        System.out.println("Try again");
}
Classic switch without break falls through to the next case — a classic silent bug.

Ternary & boolean logic

String parity = (n % 2 == 0) ? "even" : "odd";
int bigger = (a > b) ? a : b;
boolean ok = (x != 0) && (y / x > 2);    // short-circuit protects the division!

// De Morgan: !(A && B) == !A || !B      !(A || B) == !A && !B
// Ranges need BOTH sides:  if (0 <= x && x <= 100)   // not: if (0 <= x <= 100) -> ERROR

Worked micro-examples

// leap year
boolean leap = (year % 4 == 0 && year % 100 != 0) || (year % 400 == 0);

// sign of a number
String sign = (n > 0) ? "positive" : (n < 0) ? "negative" : "zero";

// find the largest of 3 without arrays
int max = a;
if (b > max) max = b;
if (c > max) max = c;

5. Loops & loop control

The four loop forms

for (int i = 0; i < n; i++) { ... }        // counted loop (0..n-1)
while (cond) { ... }                        // pre-test: may run 0 times
do { ... } while (cond);                    // post-test: ALWAYS runs once (menus!)
for (int x : arr) { ... }                   // enhanced for: read-only over array/list

break, continue, labels (from our LoopControlDemo)

for (int i = 1; i <= 10; i++) {
    if (i == 5) break;          // exit the loop entirely
    if (i % 2 == 0) continue;   // skip this iteration, go to next
    System.out.print(i + " ");  // prints: 1 3
}
outer:                          // LABELED break exits BOTH loops
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 3; j++) {
        if (found) break outer;
    }
}

8. Strings — method reference

String s = "  Hello World  ";
s.length()               // 15 (parentheses! unlike arrays)
s.trim()                 // "Hello World"  (cuts outer spaces)
s.charAt(0)              // 'H'   — single char, index 0-based

s.toUpperCase()          // "  HELLO WORLD  "
s.toLowerCase()

s.equalsIgnoreCase("hello world")
s.compareTo("abc")       // <0, 0, >0 — dictionary order ("a".compareTo("b") = -1)
s.contains("World")      // true
s.startsWith("  He")     // true      s.endsWith("d  ") // true
s.replace('l', 'L')      // "  HeLLo WorLd  "  (ALL occurrences)

// Sum of digits (int version)       // Reverse an integer (and detect overflow range)
int n = 4821, sum = 0;                long rev = 0;
while (n > 0) {                       while (n != 0) {
    sum += n % 10;   // last digit        rev = rev * 10 + n % 10;

Overloading — same name, different parameters

static int    max(int a, int b)        { return a >= b ? a : b; }
static double max(double a, double b)  { return a >= b ? a : b; }

Helpers worth writing from memory

static boolean isPrime(int n) {
    if (n < 2) return false;
    for (int i = 2; (long) i * i <= n; i++)
        if (n % i == 0) return false;
    return true;
}
static int sumDigits(int n) { int s = 0; while (n > 0) { s += n % 10; n /= 10; } return s; }
static int countDigits(int n) { if (n == 0) return 1; int c = 0; while (n != 0) { c++; n /= 10; } return c; }

Recursion — base case + progress

static long factorial(int n) {
    if (n <= 1) return 1;           // BASE CASE first!
    return n * factorial(n - 1);    // PROGRESS: n shrinks every call
}
static int fib(int n) {                       // fib: 0 1 1 2 3 5 8 ...
    if (n <= 1) return n;
    return fib(n-1) + fib(n-2);               // exponential! fine for n <= ~25
}
static long power(int base, int exp) {        // fast O(log exp) version
    if (exp == 0) return 1;
    long half = power(base, exp / 2);
    return (exp % 2 == 0) ? half * half : half * half * base;
}
static void printDigits(int n) {              // prints digits vertically

    printDigits(n / 10);
    System.out.println(n % 10);
}

Classic: balanced parentheses (stack pattern)

static boolean balanced(String s) {
    ArrayDeque<Character> st = new ArrayDeque<>();
    for (char c : s.toCharArray()) {
        if (c == '(' || c == '[' || c == '{') st.push(c);
        else if (c == ')' || c == ']' || c == '}') {
            if (st.isEmpty()) return false;
            char o = st.pop();
            if ((c == ')' && o != '(') || (c == ']' && o != '[')
                || (c == '}' && o != '{')) return false;
        }
    }
    return st.isEmpty();          // leftovers = unbalanced
}

15. Bubble, selection, insertion sort [from our repos]

Bubble sort — swap neighbors until no swaps (O(n²))

static void bubbleSort(int[] a) {
    int n = a.length;
    for (int i = 0; i < n - 1; i++)              // passes
        for (int j = 0; j < n - 1 - i; j++)      // -i: sorted tail skipped
            if (a[j] > a[j+1]) {                 // '>' asc — change to '<' for desc
                int t = a[j]; a[j] = a[j+1]; a[j+1] = t;
            }
}
Speed-up: if a whole pass does zero swaps, the array is sorted — break early (best case O(n)).

Selection sort — find the min of the rest, swap it into place

static void selectionSort(int[] a) {
    for (int i = 0; i < a.length - 1; i++) {
        int min = i;
        for (int j = i + 1; j < a.length; j++)
            if (a[j] < a[min]) min = j;          // track smallest unsorted
        int t = a[i]; a[i] = a[min]; a[min] = t; // one swap per pass
    }
}

Insertion sort — shift bigger values right, drop key in (great on nearly-sorted)

static void insertionSort(int[] a) {
    for (int i = 1; i < a.length; i++) {
        int key = a[i];                          // card being inserted
        int j = i - 1;
        while (j >= 0 && a[j] > key) {           // shift right while bigger
            a[j+1] = a[j];
            j--;
        }
        a[j+1] = key;                            // drop into the gap
    }
}

16. Merge sort & quick sort [from our repos]

Merge sort — split, sort halves, merge (stable O(n log n))

static void mergeSort(int[] a, int l, int r) {
    if (l < r) {
        int m = (l + r) / 2;             // middle (watch overflow: l+(r-l)/2 for huge r)
        mergeSort(a, l, m);              // sort left half
        mergeSort(a, m + 1, r);          // sort right half
        merge(a, l, m, r);               // combine
    }
}
static void merge(int[] a, int l, int m, int r) {
    int n1 = m - l + 1, n2 = r - m;
    int[] L = new int[n1], R = new int[n2];
    for (int i = 0; i < n1; i++) L[i] = a[l + i];
    for (int j = 0; j < n2; j++) R[j] = a[m + 1 + j];
    int i = 0, j = 0, k = l;
    while (i < n1 && j < n2)             // take smaller head each time
        a[k++] = (L[i] <= R[j]) ? L[i++] : R[j++];
    while (i < n1) a[k++] = L[i++];      // drain leftovers
    while (j < n2) a[k++] = R[j++];
}

Quick sort — partition around a pivot, recurse on both sides

static void quickSort(int[] a, int lo, int hi) {
    if (lo < hi) {
        int p = partition(a, lo, hi);
        quickSort(a, lo, p - 1);
        quickSort(a, p + 1, hi);
    }
}
static int partition(int[] a, int lo, int hi) {
    int pivot = a[hi];                   // last element as pivot
    int i = lo - 1;                      // boundary of "<= pivot" zone
    for (int j = lo; j < hi; j++)
        if (a[j] <= pivot) { i++; int t=a[i]; a[i]=a[j]; a[j]=t; }
    int t = a[i+1]; a[i+1] = a[hi]; a[hi] = t;   // pivot into final slot
    return i + 1;                        // pivot index
}

Usage + recursion picture

int[] a = {12, 11, 13, 5, 6, 7};
mergeSort(a, 0, a.length - 1);           // [5, 6, 7, 11, 12, 13]
quickSort(a, 0, a.length - 1);
// merge: depth log n, each level merges n items -> n log n guaranteed
// quick:  fastest in practice; worst case O(n^2) on already-sorted input with
//         last-element pivot (hint: pick middle or random pivot to avoid)
Contest reality: Arrays.sort(a) IS an optimized quicksort/mergesort — hand-write these only when the task asks you to implement sorting.

17. Searching: linear & binary [from our repos]

Linear search — works on ANY array, O(n)

static int linearSearch(int[] nums, int target) {
    for (int i = 0; i < nums.length; i++)
        if (nums[i] == target)
            return i;                    // found: index
    return -1;                           // convention: -1 = not found
}

Binary search — SORTED arrays only, O(log n)

static int binarySearch(int[] num, int target) {
    int start = 0, end = num.length - 1;
    while (start <= end) {
        int mid = start + (end - start) / 2;    // avoids overflow (same as (s+e)/2)
        if (num[mid] > target)  end = mid - 1;  // too big: go LEFT
        else if (num[mid] < target) start = mid + 1;  // too small: go RIGHT
        else return mid;                        // bullseye
    }
    return -1;
}

Recursive binary search

static int bsearch(int[] a, int lo, int hi, int t) {
    if (lo > hi) return -1;                     // base case: empty range
    int mid = (lo + hi) / 2;
    if (a[mid] == t) return mid;
    return (a[mid] > t) ? bsearch(a, lo, mid-1, t)
                        : bsearch(a, mid+1, hi, t);
}
ToolCallReturns
built-in (array)Arrays.binarySearch(sorted, key)index, or -(insertionPoint)-1 if absent
built-in (list)Collections.binarySearch(sortedList, key)same convention
Binary search on unsorted data gives garbage answers silently. Sort first — or use linear search.

The halving idea (why log n?)

1,000,000 items -> ~20 checks      (2^20 > 1,000,000)
1,000 items    -> ~10 checks
Loop invariant: target is ALWAYS inside [start, end]. Every check halves the range.
Common variant — FIRST occurrence with duplicates: when a[mid]==t, don't return yet: save the index and keep going left (end = mid - 1) to find the earliest.

Singly linked list — the Node pattern

        head = newNode;
    }

        Node newNode = new Node(data);

        Node cur = head;

        cur.next = newNode;

            cur = cur.next;

    }

Delete by value & search (singly)

void deleteByValue(int v) {
    if (head == null) return;
    if (head.data == v) { head = head.next; return; }   // head special case
    Node cur = head;
    while (cur.next != null && cur.next.data != v) cur = cur.next;
    if (cur.next != null) cur.next = cur.next.next;     // unlink
}
boolean contains(int v) {
    for (Node c = head; c != null; c = c.next)
        if (c.data == v) return true;
    return false;
}

Doubly linked list — prev + next

class DNode { int data; DNode prev, next; DNode(int d){ data = d; } }
class DoublyList {
    DNode head, tail;
    void insertAtBeginning(int data) {
        DNode n = new DNode(data);
        if (head == null) { head = n; tail = n; }        // first node: both point here
        else {

        }

    void displayBackward() { for (DNode c = tail; c != null; c = c.prev) System.out.print(c.data+" "); }
}

19. Circular lists & binary search trees [from our repos]

Circular linked list — traverse with do-while (stop when back at head)

class CNode { int data; CNode next; CNode(int d){ data = d; } }
CNode head, tail;
void insert(int data) {                    // append at tail, tail.next = head
    CNode n = new CNode(data);
    if (head == null) { head = n; tail = n; n.next = head; }
    else { tail.next = n; tail = n; tail.next = head; }
}
void traverse() {
    if (head == null) return;
    CNode cur = head;
    do {                                   // do-while: process head, stop at head
        System.out.print(cur.data + " ");
        cur = cur.next;
    } while (cur != head);
    System.out.println();
}
A normal while (cur != null) NEVER ends on a circular list — the last node points back to head, not null.

Binary Search Tree — insert + search + inorder print (sorted order!)

static class BST {
    BST left, right;
    int data;
    BST(int data) { this.data = data; }
}
static BST insert(BST node, int value) {          // returns (possibly new) subtree root
    if (node == null) return new BST(value);      // empty spot: place here
    if (value < node.data)      node.left  = insert(node.left,  value);
    else if (value > node.data) node.right = insert(node.right, value);
    // equal values: ignore (or count duplicates)
    return node;
}
static boolean search(BST node, int value) {      // O(log n) if tree is balanced
    while (node != null) {
        if (value == node.data) return true;
        node = (value < node.data) ? node.left : node.right;
    }
    return false;
}
static void inorder(BST node) {                   // LEFT, ROOT, RIGHT = sorted output
    if (node == null) return;
    inorder(node.left);
    System.out.print(node.data + " ");
    inorder(node.right);
}
public static void main(String[] args) {
    BST root = null;
    int[] vals = {45, 15, 79, 90, 1, 10};
    for (int v : vals) root = insert(root, v);
    inorder(root);        // 1 10 15 45 79 90  — inorder of a BST is always sorted!
}

Reusable integer-in-range reader (copy this whole method)

static Scanner sc = new Scanner(System.in);

static int readIntInRange(String prompt, int min, int max) {
    while (true) {
        System.out.print(prompt);
        String input = sc.nextLine().trim();        // read as TEXT first
        if (input.isEmpty()) { System.out.println("  [X] Empty input."); continue; }
        try {
            int value = Integer.parseInt(input);    // rejects "abc", "8.5"
            if (value >= min && value <= max) return value;
            System.out.println("  [X] Must be between " + min + " and " + max + ".");
        } catch (NumberFormatException e) {
            System.out.println("  [X] Not a whole number.");
        }
    }
}
// usage:  int score = readIntInRange("Enter score (0-100): ", 0, 100);

Text that must not be a pure number (our StringFieldValidation)

static String readNonNumericString(String prompt) {
    while (true) {
        System.out.print(prompt);
        String input = sc.nextLine().trim();
        if (input.isEmpty()) { System.out.println("  [X] Empty."); continue; }
        if (input.matches("\\d+(\\.\\d+)?"))        // "123", "45.6" rejected
            { System.out.println("  [X] That's a number. Enter text."); continue; }
        return input;                               // "John123" is OK (has letters)
    }
}

Contest strategy checklist

  • Read ALL the input format first — how many lines? separated by spaces or newlines? ends at EOF?
  • Solve the sample by hand before coding — recompute the sample output with your logic.
  • Edge cases to test always: 0, 1, negative, max value, empty line, single element, all-equal values.
  • Stuck 10 minutes? Rewrite the problem in your own words; check bounds; try n=1 by hand.
  • Submitting partial: a correct brute force beats a broken clever idea. O(n²) on n=1,000 is fine.
  • Output EXACTLY as asked — capitalization, spaces, trailing newline. "Case #1:" matters.
  • Many lines of output? StringBuilder + single print (page 10).
  • Compile mentally: every { closed, every variable declared, semicolons, correct method names.
Time-boxing: 40% reading + planning, 40% coding, 20% testing. Don't code before you can predict the sample output.
