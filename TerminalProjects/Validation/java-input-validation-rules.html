📘 Java Input Validation

Rules to Remember — A Beginner's Cheat Sheet

Java 17+ Beginner Free to Use

🎯 Rule 0 — The Golden Rule

Always read input as a String first ( nextLine() ), then validate, then convert. Never trust nextInt() / nextDouble() directly — they throw on bad input and leave junk in the buffer. 
String input = sc.nextLine();          // ✅ read as text
// ...validate...
int value = Integer.parseInt(input);   // convert only after validation

🧩 Rule 1 — The Two Directions of Type Mismatch

# Situation Example Detection
A Text where Integer expected "abc" → int try/catch around Integer.parseInt
B Number where Text expected "123" → name Character.isDigit loop
Remember: A throws an exception. B needs a scan of characters.

🔁 Rule 2 — The Validation Loop Pattern

Every validation follows the same 3-step skeleton: Read → Check → Accept . 

boolean valid = false;

while (valid == false) {
    System.out.print("Prompt: ");
    String input = sc.nextLine();          // 1. READ

    if (/* invalid */) {
        System.out.println("  [X] Try again."); // 2. CHECK
    } else {
        valid = true;                      // 3. ACCEPT
    }
}

🅰️ Rule 3 — Validate an Integer (catch "abc")

boolean isNumber = true;
try {
    Integer.parseInt(input);
} catch (Exception e) {
    isNumber = false;
}

Hook: "Try to parse; if it throws, it's not a number."

🅱️ Rule 4 — Validate Text (reject "123")

boolean allDigits = true;
for (int i = 0; i < input.length(); i++) {
    if (Character.isDigit(input.charAt(i)) == false) {
        allDigits = false;
    }
}

Hook: "If every character is a digit, it's a number — reject it."

📏 Rule 5 — Range Check Comes After Type Check 

try {
    int v = Integer.parseInt(input);
    if (v < 0 || v > 100) { /* out of range */ }
} catch (Exception e) {
    /* not a number */
}
Remember: Type first, range second.

🚫 Rule 6 — The && vs || Trap

❌ Wrong ✅ Right Why
v < 0 && v > 100 v < 0 || v > 100 Can't be both < 0 and > 100
input == "" input.isEmpty() == compares references

🧼 Rule 7 — Guard Against Empty Input

if (input.trim().isEmpty()) {
    System.out.println("  [X] Empty input.");
    continue;
}

🔢 Rule 8 — Use 3.0 Not 3 for Averages 

double avg = (a + b + c) / 3;     // ❌ integer division
double avg = (a + b + c) / 3.0;   // ✅ decimal division

🖨️ Rule 9 — Format Decimals with printf 

System.out.printf("Average: %.2f%n", avg);
Symbol Meaning
%.2f 2 decimal places
%n newline (platform-safe)

🧪 Full Skeleton to Copy-Paste

Scanner sc = new Scanner(System.in);
boolean valid = false;
int score = 0;

while (valid == false) {
    System.out.print("Enter score (0-100): ");
    String input = sc.nextLine();

    if (input.trim().isEmpty()) {
        System.out.println("  [X] Empty input.");
    } else {
        boolean isNumber = true;
        try {
            Integer.parseInt(input);
        } catch (Exception e) {
            isNumber = false;
        }

        if (isNumber == false) {
            System.out.println("  [X] Not a number.");
        } else {
            score = Integer.parseInt(input);
            if (score < 0 || score > 100) {
                System.out.println("  [X] Out of range.");
            } else {
                valid = true;
            }
        }
    }
}
System.out.printf("Accepted: %d%n", score);
