🔀 Java Conditionals Cheat Sheet

1. If / Else If / Else

if (score >= 90) {
    System.out.println("A");
} else if (score >= 80) {
    System.out.println("B");
} else {
    System.out.println("Needs Improvement");
}

2. Switch Statement (Classic)

int day = 2;
switch (day) {
    case 1:
        System.out.println("Monday");
        break; // Don't forget break!
    case 2:
        System.out.println("Tuesday");
        break;
    default:
        System.out.println("Other day");
}
Hint: If you forget the break; statement, the code will "fall through" and execute the next case as well!

3. Switch Expression (Java 14+)

String result = switch (day) {
    case 1, 7 -> "Weekend";
    case 2, 3, 4, 5, 6 -> "Weekday";
    default -> "Invalid";
};
// No breaks needed, and it returns a value!

4. Ternary Operator (Short-hand if/else)

// Syntax: condition ? value_if_true : value_if_false
int age = 20;
String status = (age >= 18) ? "Adult" : "Minor";
System.out.println(status); // Adult
