Sorting Algorithms (Time Complexity)

Algorithm Best Case Average Case Worst Case Space
Bubble Sort O(N) O(N²) O(N²) O(1)
Insertion Sort O(N) O(N²) O(N²) O(1)
Selection Sort O(N²) O(N²) O(N²) O(1)
Merge Sort O(N log N) O(N log N) O(N log N) O(N)
Quick Sort O(N log N) O(N log N) O(N²) O(log N)
Competition Tip: Always use Arrays.sort(arr) for primitives or Collections.sort(list) for objects. Under the hood, Java uses TimSort (a hybrid of Merge Sort and Insertion Sort) which is incredibly fast and stable.

Binary Search Tree (BST) Rules

  • Left Child must be less than the parent.
  • Right Child must be greater than the parent.
  • In-order Traversal (Left -> Root -> Right) always prints the tree in sorted order . 
void display(Node node) { // In-order Traversal
    if (node == null) return;
    display(node.left);
    System.out.print(node.data + " ");
    display(node.right);
}

Linked List Basics

A Linked List is made of Node objects. Each node holds data and a next pointer. 

class Node {
    int data;
    Node next;
    Node(int data) { this.data = data; this.next = null; }
}

Insert at Start (O(1))

Node newNode = new Node(data);
newNode.next = head;
head = newNode;

Delete a Node (O(N))

You must traverse from head to find the node before the one you want to delete, then change its .next pointer.
