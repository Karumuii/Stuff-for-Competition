⚡ The Three Core Controls — Side by Side

break

break;

Exits the innermost loop entirely.

for i=1..5
  if i==3 break;
  print i
→ 1 2
continue

continue;

Skips the rest of this iteration . Loop keeps going.

for i=1..5
  if i==3 continue;
  print i
→ 1 2 4 5
return

return;

Exits the whole method , not just the loop.

for i=1..5
  if i==3 return;
  print i
→ 1 2 (method ends)

🚪 1. break

One-liner: "I'm leaving the room." — exits the innermost loop immediately. 
for (int i = 1; i <= 10; i++) {
    if (i == 5) {
        System.out.println("Hit 5 — stop.");
        break;                // ← exits loop entirely
    }
    System.out.println("i = " + i);
}
// Output: i = 1  i = 2  i = 3  i = 4  Hit 5 — stop.

⏭️ 2. continue

One-liner: "Skip this one, next please." — jumps to the next iteration. 
for (int i = 1; i <= 6; i++) {
    if (i % 2 == 0) {
        continue;             // ← skip even numbers
    }
    System.out.println("Odd: " + i);
}
// Output: Odd: 1  Odd: 3  Odd: 5

🏃 3. return

One-liner: "I'm leaving the building." — exits the whole method . 
static void search(int[] arr, int target) {
    for (int i = 0; i < arr.length; i++) {
        if (arr[i] == target) {
            System.out.println("Found at " + i);
            return;           // ← exits the METHOD entirely
        }
    }
    System.out.println("Not found");
}
// After return, nothing else in the method runs — not even "Not found".

🚪🚪 4. Labeled break (escape nested loops)

One-liner: "Leaving this room and the whole floor." — breaks out of an outer loop. 
outer:
for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 3; j++) {
        if (i * j == 6) {
            System.out.println("Found at (" + i + "," + j + ")");
            break outer;      // ← exits BOTH loops
        }
        System.out.println("i=" + i + ", j=" + j);
    }
}
// Output stops at: i=2, j=2 → Found at (2,3)

🔄 5. Labeled continue (skip an entire outer iteration)

One-liner: "Skip to the next floor — forget this row." — jumps to the next iteration of the outer loop. 
outer:
for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 3; j++) {
        if (j == 2) {
            continue outer;   // ← skip the rest of row i
        }
        System.out.println("i=" + i + ", j=" + j);
    }
}
// Output only prints j=1 for each i: (1,1) (2,1) (3,1)

🎢 6. do-while with break

One-liner: "Ride once, then ask if again." — body runs at least once . 
int n = 0;
do {
    n++;
    if (n == 3) {
        System.out.println("n reached 3 — break.");
        break;
    }
    System.out.println("n = " + n);
} while (n < 10);
// Output: n = 1  n = 2  n reached 3 — break.

🎁 7. Returning a value from inside a loop

Pattern: search until found → return the result → otherwise fall through to a default. 
static int findIndex(int[] arr, int target) {
    for (int i = 0; i < arr.length; i++) {
        if (arr[i] == target) {
            return i;           // ← hand back the answer, exit method
        }
    }
    return -1;                  // not found
}

🧩 8. Real-world combo — validation loop

Uses return , continue , and an infinite loop — no valid flag needed. 

static int readScore(Scanner sc) {
    while (true) {
        System.out.print("Score (0-100, 'q' to quit): ");
        String input = sc.nextLine().trim();

        if (input.equalsIgnoreCase("q")) {
            return -1;              // RETURN — abort
        }
        if (input.isEmpty()) {
            System.out.println("  [X] Empty.");
            continue;               // CONTINUE — retry
        }

        int value;
        try {
            value = Integer.parseInt(input);
        } catch (Exception e) {
            System.out.println("  [X] Not a number.");
            continue;               // CONTINUE — retry
        }

        if (value < 0 || value > 100) {
            System.out.println("  [X] Out of range.");
            continue;               // CONTINUE — retry
        }
        return value;               // RETURN — good value
    }
}

🧠 Memory Hooks

🚪 break — "I'm leaving the room (loop)."
⏭️ continue — "Skip this one, next please."
🏃 return — "I'm leaving the building (method)."
🚪🚪 break outer; — "Leaving this room and the whole floor."
🔄 continue outer; — "Skip to the next floor."
🎢 do-while — "Ride once, then ask if again."

⚠️ Common Mistakes

1. Unreachable code after return / break

if (x == 0) {
    return;
    System.out.println("never runs");   // ❌ compile error
}

2. Infinite loop — continue skips the update

int i = 0;
while (i < 10) {
    if (i == 3) continue;   // ❌ i never increments → infinite
    i++;
}
// Fix: increment i BEFORE the continue, or use a for-loop.

3. break in switch vs loop

Inside a switch , break exits the switch , not the surrounding loop. Use a labeled break to leave the loop from inside a switch.

4. Confusing break and return

You want... Use
Stop this loop, but keep the method running break
Stop this loop and leave the method return
Stop this loop and hand a value back to the caller return value;

🌳 Decision Flow

If you need to… Use
Skip the rest of this iteration continue
Exit the current loop break
Exit nested loops at once break outer;
Skip to the next outer iteration continue outer;
Exit the method with a result return value;
Exit the method with no result return;
Run body at least once do { } while (cond);
Loop forever until a condition fires while (true) { … }
break → exit loop · continue → skip iteration · return → exit method
Labels ( break outer; / continue outer; ) let you control which loop. do-while always runs once. while(true) + return is the cleanest validation loop.
